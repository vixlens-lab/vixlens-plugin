## Como sincronizar com os arquivos locais

Os arquivos `paleta-cores.md` e `paleta-tipografia.md` nesta pasta são uma **cópia local** do que está no DS online, formatada para consumo por Claude Code (que não tem acesso direto ao DS online sem WebFetch).

Quando o DS oficial atualizar, refletir nos arquivos locais via:
1. Sessão Claude Code → `WebFetch` no DS online
2. Atualizar os `.md` correspondentes
3. Commit

## Observação

Se a equipe Vixlens atualizar o DS frequentemente, vale considerar:
- Buscar via API/scraping do DS site
- Ou hospedar os arquivos `.md` num repo público e referenciar
